FoodLab Studio v0.4.0 —— GitHub Pages 上传说明

一、上传方法
1. 解压本压缩包。
2. 将以下文件上传并覆盖到 foodlab-studio 仓库根目录：
   index.html
   styles.css
   app.js
   service-worker.js
3. GitHub 提交完成后等待 1～3 分钟。
4. 打开网站后进行一次强制刷新；手机端如仍显示旧版，可清除该网站缓存后重新打开。

二、本版实际完成
1. 研究设计页
   - 实验名称、指标、单位
   - 单因素/双因素
   - 因素名称、水平、重复数
   - SD、SE、95% CI 误差类型
2. 动态模板
   - 按研究设计生成可填写 Excel 模板
   - 同时提供 CSV 模板
   - Excel 中包含“数据填写”“项目配置（勿改）”“填写说明”
3. 数据导入
   - 读取模板 Excel、CSV、TSV
   - 检查空值、非数字、重复组合
   - 原始数据预览
4. 统计分析
   - n、Mean、SD、SE、CV、95% CI
   - 单因素 ANOVA
   - 平衡设计双因素 ANOVA（含交互作用）
   - Fisher's LSD（α=0.05）显著性字母
   - 自动生成谨慎的文字结果解读
5. 论文图工作台
   - 折线图/柱状图
   - 柱状图自动使用色块图例；折线图自动使用线+点图例
   - 真实上下双绘图区断轴，左右坐标轴同步断开
   - 横坐标刻度线正常显示
   - 点击并拖动图题、横坐标标题、纵坐标标题和图例
   - 点击坐标轴修改范围、刻度、粗细和标题位置
   - 点击数据系列修改颜色、线宽、点型、柱宽和边框
   - 点击误差棒、显著性字母、边框进行编辑
   - SVG / 高清 PNG 导出

三、当前边界
- 双因素 ANOVA 当前要求各因素组合的重复数相同；使用平台生成的模板即可保证这一点。
- 显著性字母当前采用 Fisher's LSD；Tukey、Duncan 和重复测量 ANOVA 尚未接入。
- PCA、PLS-DA、HCA、相关性和回归页面目前是后续模块入口，尚未实现真实计算。
- Excel 功能使用 SheetJS Community Edition 的浏览器组件；若组件因网络原因未加载，软件会自动提示使用 CSV 模板。
