分析总览

按分析任务组织，而不是按 pH、TBARS 等指标拆分。

统一工作流

数据 → 统计 → 图表 → 论文输出

任意食品实验指标都可以使用同一套单因素、双因素、PCA、聚类和图表编辑引擎。

Excel / CSV→统计检验→Chart Studio→SVG / PNG

数据中心

当前版本先提供通用长表粘贴和示例载入。后续可接入 Excel 文件解析。

推荐列：x、group、mean、sd、letter。每行代表一个“时间 × 处理”组合。

基础统计

规划：Mean、SD、SE、CV、95%CI、正态性、方差齐性和异常值检查。

显著性分析

规划：单因素 ANOVA、双因素 ANOVA、重复测量、Tukey、Duncan、LSD、Bonferroni，并把显著性字母传给图表工作台。

当前图表工作台已支持读取 letter 列并显示 a、ab、b 等字母；自动统计将在后续模块接入。

PCA / PLS-DA

PCA：探索样品整体差异，常见输出为得分图、载荷图和双标图。

PLS-DA：监督分类，常见输出为得分图、VIP 图、交叉验证和置换检验。

该页先作为模块入口，后续接入真实矩阵计算。

HCA / 热图

HCA 是层次聚类分析，常见输出为树状图；与标准化热图组合后，可同时看样品/指标聚类和数值高低。

相关性分析

Pearson 适合线性关系，Spearman 适合单调关系或非正态数据。常见图形为相关矩阵热图和网络图。

回归分析

规划：简单线性回归、多元回归、PLS 回归和模型诊断。

论文输出

规划：Figure、Table、Caption、统计结果表、Word 与 LaTeX 导出。
