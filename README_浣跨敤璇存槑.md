# 食品实验数据分析平台（FoodLab Studio）v0.2.1

## 本次修复

- Excel 打开后第一个工作表直接是 **“数据填写”**，不再先显示项目配置。
- pH 模板只需填写 **pH** 列；色泽模板只需填写 **L*、a*、b*** 列。
- 样品编号、因素水平、平行编号和测量重复编号由软件自动生成，请勿修改。
- “项目配置（勿改）”移到第二个工作表，仅供软件识别。
- 导入功能同时兼容新表名“数据填写”和旧表名“原始数据”。
- 软件名称更新为 **食品实验数据分析平台**。

## 如何运行

Windows 解压后双击 `start_windows.bat`。浏览器会打开本地地址。若脚本受限，可双击 `open_without_server.bat`。

## 正确使用流程

1. 首页选择 pH 或色泽。
2. 在软件界面设置实验因素、水平、独立平行数和测量次数。
3. 点击“下载可填写 Excel 模板”。
4. 打开 Excel 的第一个工作表“数据填写”。
5. pH 实验只填写 pH 列；色泽实验只填写 L*、a*、b* 列。
6. 保存后返回软件，在“导入校验”中导入该文件。

例如 pH、单因素储藏时间、3 个独立平行样品、各测 1 次时，表格会自动生成 0 d 的 3 行、2 d 的 3 行……实验员只需在对应行填入 pH 原始值。

## 当前限制

- 动态 XLSX 导入/导出暂时使用在线 SheetJS 组件；无网络时可使用 CSV。最终 EXE/APK 将内置依赖。
- Tukey、Duncan、LSD、Bonferroni 等后续统计模块仍在开发清单中。
